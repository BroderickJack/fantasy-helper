# Changelog

## v1.0.0 — 2026-11-16

First QRFFL website release:

- League home with weekly matchup scores and comparisons against the average.
- Live scores with week selection, projections, and automatic refresh.
- Championship archive with support for league-supplied historical records.
- Analytics for franchise history, all-play results, and trade studies.
- Q-alytics statistical notes, powered by QuailGPT.
- Laegue Average's current matchup, season records, and historical game log.

The site runs on static hosting with no build step, backend, or paid API.
